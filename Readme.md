# Basic Calculator

A simple command-line calculator developed using C++ as part of my Pinnacle Labs C++ Programming Internship.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Menu-driven interface
- Division-by-zero handling
- Invalid-choice handling

## Technologies

- C++
- C++ Standard Library

## How to Run

```bash
g++ main.cpp -o calculator
./calculator

# Number Base Converter in C++

A robust number system converter supporting bidirectional conversions between Decimal, Binary, and Hexadecimal representations.

## Features
- **Decimal Conversion**: Convert decimal integers into binary and hexadecimal.
- **Binary Conversion**: Convert binary strings into decimal and hexadecimal.
- **Hexadecimal Conversion**: Convert hexadecimal strings into decimal and binary.
- **Error Handling**: Uses `try-catch` blocks and string stream validation for invalid characters.

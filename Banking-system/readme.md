# Banking System in C++

A console-based Banking System application featuring secure account operations and detailed transaction logging.

## Features
- **Account Management**: Create accounts with auto-generated account numbers and PIN protection.
- **Transactions**: Secure deposits and withdrawals with balance verification.
- **Transaction History**: Tracks every transaction along with closing balances.
- **OOP Architecture**: Encapsulated state and business logic using modern C++ classes.

## Compilation & Run
```bash
cd Banking-System
g++ main.cpp -o banking.exe
./banking.exe
